Реализовать трансляцию кода c/c++ в asm
Используемые операции с переменными:
    -Сложение +
    -Вычитание +
    -Умножение +
    -Деление (mod, div) +/+
    -Присвоение +
    -Инициализация +
Предусмотреть использование функций (функция инициализуруется до ее использования)


result = [func_name_1:[oper1, oper2, ..., oper_n], func_name_2:[oper1, oper2, ..., oper_n], ..., func_name_n:[oper1, oper2, ..., oper_n]]

Для реализации функций:
    1.Проходимся по списку result, ищем функцию main
    2.На основе списков data и result функции main заполняем тело программы
        2.1.Если встетилась функция пишем только ее вызов
    3.Заполняем остальные функции
